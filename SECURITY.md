# Security Policy

Do not open a public issue for a security vulnerability.

Report it privately through GitHub's security advisory form: https://github.com/VladButacu/mission-control/security/advisories/new

Include the affected version, the steps to reproduce, and the impact you expect.

Disclosure timeline: we publish details of a reported vulnerability 30 days after the report is received.

Response timeline: we acknowledge a report within 3 business days and aim to ship a fix within 30 days of the report.
